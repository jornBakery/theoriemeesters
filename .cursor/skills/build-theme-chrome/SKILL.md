# Build Header or Footer

1. Analyse all supplied responsive mockups.

2. Identify:
   - logo
   - navigation
   - CTA
   - utility links
   - account/cart elements
   - responsive/mobile menu behavior

3. Use Elementor Pro Theme Builder.

4. Do not use EMCP Themer for this project.

5. Create the template as draft.

6. Build template content with normal Elementor containers and widgets.

7. Verify its Elementor structure.

8. Run visual QA.

9. Only after QA passes may display conditions be assigned.

10. Do not publish without explicit approval.
