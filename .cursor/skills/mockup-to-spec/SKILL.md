# Mockup to specification workflow

1. Locate all mockups for the page.

2. Ensure desktop, tablet and mobile versions are considered when available.

3. Delegate visual analysis to the mockup-analyst subagent.

4. Produce:
   - design-system.md
   - components.md
   - pages/<slug>.md

5. Identify reusable components.

6. Map components to likely Elementor widgets.

7. Record uncertain assumptions.

8. Do not make WordPress changes.

9. Present the resulting implementation plan before building.
