# Visual matching workflow

1. Open the built page.

2. Compare it against each supplied mockup.

3. Delegate independent review to visual-qa.

4. Prioritize:
   Critical → Major → Minor.

5. Ask elementor-builder to make targeted corrections.

6. Never regenerate the full page for small styling differences.

7. Reinspect the page after changes.

8. Repeat for a maximum of 3 correction rounds unless instructed otherwise.

9. Report remaining differences.
