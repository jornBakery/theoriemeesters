# Build Elementor page

Prerequisite:
The page must already have an approved specification.

1. Read the design system.
2. Read component definitions.
3. Read the requested page specification.

4. Inspect current Elementor globals.

5. Discover required Elementor widgets.

6. Inspect widget schemas when unfamiliar controls are needed.

7. Create the target page as draft if it does not exist.

8. Delegate implementation to elementor-builder.

9. Build major structure before styling fine details.

10. Apply responsive settings.

11. Read back the resulting page structure.

12. Confirm:
   - no unintended widgets
   - no duplicate sections
   - correct nesting
   - correct global references

13. Never publish automatically.

14. Hand the completed draft to visual QA.
